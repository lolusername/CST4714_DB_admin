## Abstract

*Operating Cloud Databases* is a beginner-friendly, lab-first open course for
database administration. It begins with a substantial review of the relational
model, relational algebra, and SQL, then develops practical skills in schema
integrity, safe change, transactions, concurrency, security, query plans,
indexing, backup, restore, NoSQL history, JSON, MongoDB Query Language, document
modeling, aggregation, validation, reliability, scaling, polyglot systems, and
career communication. One recurring service-desk case and one operating cycle -
state a promise, inspect evidence, make a controlled change, and verify the
result - connect the course. The package includes 15 open-text modules, 15
weekly guides, 25 individual labs, six executable notebooks, three reusable data
packages, assessments, canonical midterm and final projects, 15 student-facing
slide decks with complete spoken scripts, transcripts, PDF handouts, and public
instructor implementation guides. Cloud activities use free PostgreSQL/Supabase
and MongoDB/Atlas environments while preserving local or static alternatives.
