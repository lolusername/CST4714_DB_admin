# Sources, Adaptations, and Attributions

This file records resources that shape the course. External pages are linked
rather than copied unless their licenses explicitly permit adaptation. Free
access does not by itself make a resource open: an OER must also grant reuse and
adaptation rights through an open license.

## Dataset Attributions

- `datasets/metro_support/` is an original synthetic dataset released under CC0.
- `datasets/mini_inventory/` is an original synthetic dataset released under CC0.
- `datasets/cisa_kev_sample/` is a field-reduced, 75-record teaching subset of
  CISA's official [Known Exploited Vulnerabilities JSON
  feed](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json),
  retrieved July 13, 2026. CISA source data retains applicable U.S. government
  terms. The package README records fields, omissions, source metadata, and
  transformation; course-authored transformation code is MIT licensed.
- Any later snapshot of a public dataset must include its source URL, retrieval
  date, data license or terms, and transformation notes in that dataset's README.

## Attribution Practice for Adopters

When adapting a module, preserve this file, add the title and URL of any new
source, identify what changed, and retain any source-specific license notice.
