# Critical and Career-Connected Writing

Complete eight short responses across the term. Each response is 150-250 words
unless the prompt says otherwise and is submitted as plain text in Brightspace.
Do not create a separate repository or document unless instructed.

## The C-E-T Pattern

Use a compact professional structure:

- **Claim:** answer the question directly.
- **Evidence:** name a query result, plan node, policy test, document example,
  recovery check, course reading, or official source that supports the claim.
- **Tradeoff:** identify what the choice costs, risks, or leaves unresolved.

## Response 1: Shared Responsibility

A managed database platform handles some operational work but not all of it.
Choose one responsibility owned by the provider and one still owned by the user.
Explain one failure that could happen if a team confuses the boundary.

## Response 2: Integrity Is a User Experience

Choose one constraint from your Week 3 schema. Explain which bad state it prevents,
how a user or application might encounter that state, and why application-only
validation would or would not be enough.

## Response 3: Incident Update

Write a workplace-style status update about the blocking incident from Week 5.
State impact, evidence, mitigation, verification, and the next prevention step.
Avoid blame and unsupported certainty.

## Response 4: Least Privilege Decision

Defend one access decision from Week 6. Identify the actor, the minimum action
they need, a test proving what is allowed, and a test proving what is denied.

## Response 5: Performance Recommendation

Using your Week 7 before/after plans, recommend whether the index should be kept.
Use plan evidence and discuss at least one write, storage, or maintenance cost.

## Response 6: Tables to Documents

Defend one JSON or MongoDB design for the Metro Support workload. Compare it with
one plausible alternative. Explain which access pattern your design makes easier
and which update it makes harder.

## Response 7: Reliability Promise

Write a short response to a manager who says, "The database is in the cloud, so
we cannot lose data." Explain the limits of that statement and name concrete
backup, restore, replication, or verification evidence the team should request.

## Response 8: Interview Story

Use Situation-Task-Action-Result-Reflection to describe one course incident or
project decision. The result must include evidence, and the reflection must name
what you would inspect or change next in a production system.
