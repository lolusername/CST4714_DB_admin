# Assessment and Learning-Evidence System

This course uses frequent, low-stakes evidence to decide what needs reteaching and
to help students see their own progress.

## Evidence Sources

- [Beginning diagnostic](diagnostic.md): ungraded prior-knowledge inventory.
- [Retrieval and exit prompt bank](retrieval_exit_bank.md): module-aligned,
  no-notes practice for most meetings.
- Individual labs: one small artifact per class.
- Exit checks: one evidence-and-tradeoff question.
- [Critical and career writing](critical_writing.md): eight short responses.
- [Common rubrics](rubrics.md): observable criteria shared across labs and writing.
- [End-of-course inventory](post_course_inventory.md): paired concept,
  confidence, access, and material feedback.
- Midterm and final: integrated demonstrations of the course outcomes.

## How Evidence Changes Teaching

The instructor records aggregate class patterns, not public student-level
profiles. If fewer than 70 percent of submitted responses correctly identify the
core concept, the next class begins with a different worked example. If 70-84
percent succeed, the next retrieval check includes one targeted item. At 85
percent or above, instruction advances while the concept returns later through
spaced retrieval.

The numbers are decision prompts, not automatic judgments. The instructor also
examines error types, missing submissions, access barriers, and student questions.
No grade prediction or automated risk label is assigned to a student.
