# Beginning Diagnostic: How Do You Think About Data Systems?

This diagnostic is ungraded. Answer without searching so the class can identify
what it already knows and what needs more attention.

## Part A: Concepts

1. In your own words, distinguish a database from a database management system.
2. A spreadsheet contains a column named `status`. What could go wrong if every
   user can type any value into that column?
3. What is a primary key for?
4. What is the difference between filtering rows and sorting rows?
5. What do you think a database transaction protects?
6. Why might giving every application user full administrator access be risky?
7. What would count as proof that a backup is usable?
8. What might an index improve, and what might it cost?
9. What does JSON look like? Write a tiny example if you can.
10. When might one record contain a list of smaller records instead of storing
    those smaller records in a separate table?

## Part B: Confidence

Rate each statement from 1 (not yet) to 5 (I can explain and demonstrate it).

- I can write a basic SQL query.
- I can create related tables with keys.
- I can interpret a database error message.
- I can use GitHub to save a text or code artifact.
- I can protect a password or connection string.
- I can explain a technical choice using evidence.

## Part C: Access

Privately tell the instructor about any barrier to using GitHub, Supabase,
MongoDB Atlas, Google Colab, or a personal computer. This question is about
planning an equivalent path, not evaluating you.
