# About This Book

*Operating Cloud Databases* is a beginner-friendly, lab-first course for
CST4714 Database Administration. It teaches students to build, query, secure,
diagnose, recover, and explain small database systems using PostgreSQL,
Supabase, MongoDB, Atlas, Python, and open local alternatives.

The course begins with a substantial relational-model, relational-algebra, and
SQL review. It then develops operational skills through one recurring Metro
Support case. Students repeatedly identify an operating promise, inspect
evidence, make one controlled change, and verify the result.

## How to Use the Book

Each module contains:

- an operating question;
- measurable learning outcomes;
- concise conceptual instruction;
- annotated SQL, MQL, JSON, or Python examples;
- a worked example;
- common misconceptions;
- individual practice; and
- retrieval and transfer questions.

The complete course package also contains weekly guides, 25 individual labs,
six executable notebooks, datasets, student-facing slide decks, exact spoken
transcripts, assessments, projects, and public instructor implementation
guides. Those reusable files are available in the source repository.

## Access and Cost

No student must purchase a textbook, subscription, certification, or database
plan. Cloud activities use free services and include a local, static, or
simulated route when an account or network barrier prevents cloud access.

## Accessibility

The canonical text uses semantic Markdown headings, descriptive links, text
tables, and code blocks. Every slide deck has a complete structured-text
transcript. Cloud-only activities provide equivalent evidence paths. Readers
may use the web, EPUB, Word, or source Markdown format that works best with
their device and assistive technology.
