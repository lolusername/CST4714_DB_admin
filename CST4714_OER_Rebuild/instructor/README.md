# Public Instructor Adoption Package

These openly licensed guides support adoption and adaptation of *Operating Cloud
Databases*. They are instructor-facing OER, not private grading materials.

- [Course implementation guide](implementation_guide.md): 15 module-aligned
  lesson plans, prerequisites, live demonstrations, misconceptions, fallbacks,
  and evidence decisions.
- [Technical setup and troubleshooting](technical_setup_troubleshooting.md):
  account, connection, network, TLS, tool-version, and credential-safety guidance.
- [Accessibility and adaptation](accessibility_adaptation.md): authoring,
  presentation, notebook, lab, and equivalent-path practices.
- [Data-informed teaching protocol](data_informed_teaching.md): low-stakes evidence,
  aggregate decision rules, privacy, and revision records.
- [Production, validation, and release guide](../RELEASE_CHECKLIST.md): inventory,
  technical, accessibility, licensing, privacy, and release checks.

The [fellowship planning documents](../fellowship/README.md) remain separate from
these reusable teaching resources. Private answers, student records, and private
grading comments do not belong in this directory or in a public release.
