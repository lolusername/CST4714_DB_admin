# MongoDB Student Certification Guide

As of March 19, 2026, MongoDB's official student page says students can qualify for free MongoDB certification and a $50 Atlas credit through the GitHub Student Developer Pack.

## Important Clarification
This is not described as instant exam access for every student who lands on the page.
MongoDB's official student FAQ says students must complete a specific student-verification and learning-path process first.

## Quick Version
1. Get approved for GitHub Student first.
2. Go to MongoDB for Students.
3. Verify your student status with your GitHub information.
4. Open the certification learning path in MongoDB University.
5. Complete and pass all courses in that path.
6. Use the certification benefit only after those steps are complete.

## What MongoDB Says You Must Do
MongoDB's student FAQ says students must:
1. be enrolled in the GitHub Student Developer Pack,
2. verify student status at `mongodb.com/students`,
3. complete and pass all courses associated with a certification learning path in MongoDB University.

MongoDB's student page describes the benefit as:
- free MongoDB certification, valued on the page at $150,
- and a separate $50 Atlas credit.

## What To Do In Order
1. Finish your GitHub Student application and wait for approval.
2. Visit MongoDB for Students.
3. Use the GitHub-connected student flow shown there.
4. Follow the certification learning path linked from the student page.
5. Complete the required courses before expecting certification access.

## Common Mistakes
- Trying to start with MongoDB before GitHub Student approval is complete.
- Assuming the free certification benefit appears immediately.
- Stopping after verification without finishing the required learning path.
- Relying on third-party blog posts instead of MongoDB's own student page and FAQ.

## Why This Matters In This Course
- Atlas is the MongoDB cloud platform students will start seeing in Week 8.
- The student benefit lowers the barrier to trying Atlas and working toward certification.
- The process also gets students used to official product documentation rather than guesswork.
