# Week 14 Lab Day 2
## Final Project Report, Presentation, and Submission Check

## Purpose
Today you will prepare the final version of your project explanation and presentation.

The final project is due May 26, 2026.

## Individual Work Only
This lab is individual.
There is no group work.

## What To Do

### 1. Final Report Outline
Create an outline for your 700-1000 word written explanation.

Use these sections:

1. project purpose
2. platform choice
3. data model explanation
4. seed data explanation
5. query examples
6. admin and reliability decisions
7. what you would improve with more time

### 2. Presentation Plan
Create a 5-7 minute presentation plan.

Use this structure:

1. what the database manages
2. why you chose the platform
3. the data model
4. one useful query
5. one admin/reliability decision
6. one lesson learned

### 3. Evidence Checklist
Check whether you have each item.

- schema or model files
- seed data
- at least four query examples
- at least one index decision
- access-control or permission concern
- backup/restore plan
- restore verification checklist
- instructor review access or submission evidence
- short written explanation
- short presentation materials

### 4. Final Cleanup
Write what still needs to be finished before May 26, 2026.

Use a short checklist.

## In-Class Checkpoint
Submit one Brightspace text response.

Include:
1. final report outline
2. presentation plan
3. evidence checklist
4. final cleanup checklist

## Success Standard
You are successful if you know exactly what is complete, what remains, and how your final project will be graded.
