# Industry/Career Connection: Buffer: reporting grain and bounded documents

Buffer's 2014 engineering account describes MongoDB aggregation reports and a redesign after growing embedded event arrays reached the document-size limit. Read it as a historical case, not current product documentation: modern MongoDB supports collection validation. The connection to this lab is deciding what one result row counts and whether an array can grow without bound. An analytics engineer should deliver a report whose population can be traced back to source IDs, rather than presenting a plausible total alone.

[Read the company’s own account](https://buffer.com/resources/how-buffer-uses-mongodb-to-power-its-growth-platform/).
