## Using the Files

Download the folder as a ZIP before opening a local HTML textbook or notebook.
GitHub displays Markdown and notebook source, but does not execute notebooks or
render a local HTML book as a website. In Colab use **File > Upload notebook**.
The three notebooks include their setup and explain their execution environment.

The classroom materials have undergone the checks summarized in
[REVIEW_STATUS.md](REVIEW_STATUS.md). They are not certified accessible exports
or an approved institutional OER release. Structured chapters and transcripts
provide alternatives to slide PDFs. Ask the instructor for an accommodation.
