# Course Notebooks

The notebooks are executable lessons, not separate assignments unless the weekly
page says to submit one. Open the matching week page for context and directions.

Download the linked `.ipynb` file, open Colab, and choose **File > Upload notebook**.
The full draft is distributed as a course package, not posted on public GitHub.
Local Jupyter is also supported.
