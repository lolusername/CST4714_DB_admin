# CST4714 Database Administration

**Fall 2026 | Professor Atilio Barreda**

**Contact:** [abarreda@citytech.cuny.edu](mailto:abarreda@citytech.cuny.edu)

How do you keep a database useful when people change data at the same time,
queries give misleading answers, or something breaks? This course combines a
substantial SQL review with hands-on work in PostgreSQL/Supabase and MongoDB/Atlas.
You will practice modeling, querying, access control, performance, and recovery.

## Week 1: How Applications Use Databases

A campus repair request was saved successfully, but it is missing from the
staff dashboard. We will trace the request through an application and use a
small set of tables to explain what happened.

**Day 1:** Follow a request from the browser through the application to the
database. Distinguish storing a record from retrieving it for a dashboard.

**Day 2:** Review rows, keys, missing values, selection, projection, and joins.
Use those ideas to finish the same lab. Submit one individual text response
in Brightspace.
