# Week 3: Postgres Admin + DevOps in Supabase

## Week Focus
Week 3 introduces practical database administration and DevOps operations in Supabase.

Core themes:
- managed Postgres shared-responsibility model
- operational workflows (plan, change, verify, recover)
- Supabase admin surfaces for day-to-day work
- backups and restore-first thinking
- security model with roles and RLS

## Learning Outcomes
By the end of Week 3, students should be able to:
1. Explain what the team still owns in managed Postgres.
2. Navigate key Supabase admin/ops features confidently.
3. Use migration-first habits for structural changes.
4. Verify changes with SQL checks and operational evidence.
5. Connect database security controls (roles + RLS) to real use cases.
