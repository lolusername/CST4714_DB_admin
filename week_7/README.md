# Week 7: Midterm Review & Practice Lab

## Learning Objectives
- Synthesize core database administration concepts from Weeks 1–6 in preparation for the midterm.
- Diagnose and optimize SQL queries that use joins, window functions, and transaction controls.
- Evaluate schema design and normalization trade-offs in realistic case studies.
- Connect cloud DBA responsibilities to on-premise PostgreSQL administration tasks.
- Outline individual next steps for the midterm project deliverables.

## Session Snapshot
1. **Check-In & Diagnostic (15 min)** — short quiz to surface review priorities.
2. **Architecture & Cloud Roundtable (25 min)** — recap PostgreSQL internals plus cloud service operations.
3. **SQL Deep Dive (45 min)** — targeted practice on functions, views, triggers, and transactions.
4. **Normalization Studio (35 min)** — group refactor of a flawed schema with peer critique.
5. **Performance & Troubleshooting Drills (30 min)** — fast-paced scenarios on locks, isolation, and maintenance.
6. **Midterm Project Huddle (15 min)** — clarify expectations and plan next steps.
7. **Exit Ticket & Study Plan (10 min)** — students commit to priority review items.

- Encourage completion of any outstanding normalization lab or transaction notebook tasks from Weeks 4–5.
- Share the `student_review_packet.md` ahead of class and prompt learners to flag top-three problem areas.

## Midterm Project Alignment
- Revisit Week 4 proposal expectations and Week 5 schema feedback guidelines.
- Provide five-minute desk checks during the project huddle to unblock scope, schema, or tooling questions.
- Remind students of posting requirements for draft ERDs and write-ups before the midterm checkpoint.
