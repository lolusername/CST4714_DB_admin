# Week 8 – MongoDB & NoSQL Foundations

## Materials
- `teacher_guide_mongodb_intro.md` — agenda, facilitation notes, and assessments for the single-session MongoDB introduction.
- `teacher_self_study_mongodb.md` — self-paced roadmap to prepare instructors with MongoDB skills and demos.
- `mongodb_nosql_intro.pptx` — slide deck covering NoSQL history, MongoDB principles, query demos, and student onboarding steps.
- `MongoDBShellCheatSheet.pdf` — printable reference listing high-frequency `mongosh` commands, CRUD patterns, query operators, aggregation helpers, indexes, and admin tooling.

## Recommended Flow
1. Review the self-study roadmap, then rehearse commands from the shell cheat sheet.
2. Adapt the instructor guide timings and slides to fit your class period.
3. Share the cheat sheet with students during the lab so they can reinforce core syntax beyond the demo.
4. Assign the Joining Array Fields lab post-class and collect the completion-screen screenshot for grading.
