# Week 9 - NoSQL Models Beyond Documents

This week broadens the course from MongoDB-style document thinking into a wider NoSQL landscape.
The main lecture compares four important model families:
- key-value stores,
- document databases,
- graph databases,
- vector databases.

The goal is not to sell one model as universally best.
The goal is to show students that different database models exist because they answer different kinds of questions well.

## Materials
- `Week_09_NoSQL_Models_KeyValue_Document_Graph_Vector.pptx` - detailed lecture deck with diagrams, model comparisons, and speaker notes that contain instructor focus bullets instead of a word-for-word script.

## Week Focus
- understand why multiple NoSQL models exist,
- connect each model to its natural workload and query style,
- introduce graph concepts such as nodes, edges, paths, cycles, and centrality,
- introduce vector search concepts such as embeddings, nearest neighbors, cosine similarity, and approximate search,
- compare practical tradeoffs rather than treating NoSQL as one single thing.
