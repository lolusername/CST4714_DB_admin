# Week 12 Lab
## MongoDB Atlas Jumpstart Using Python

## Purpose
This lab helps you practice the basic workflow of using MongoDB Atlas from Python.

You will complete a MongoDB University lab that walks through creating, deploying, and connecting to an Atlas cluster using Python.

## Lab Link
Open the MongoDB University lab here:

[Atlas Jumpstart Using Python Lab](https://learn.mongodb.com/learn/course/atlas-jumpstart-using-python-lab-only/main/atlas-jumpstart-using-python-lab-only?client=educators)

## Individual Work Only
This lab is individual.
There is no group work.

## What To Do
Complete the linked MongoDB University lab.

As you work, focus on these ideas:
- how Atlas organizes projects, clusters, databases, and collections
- how a Python application connects to Atlas
- what information belongs in a connection string
- why database credentials should not be posted publicly
- how sample data, queries, and code connect to each other

## Security Rule
Do not submit or screenshot anything that exposes:
- your full connection string
- your database password
- private keys
- access tokens
- secrets from an `.env` file

If a screenshot shows a secret, crop it or blur it before submitting.

## In-Class Checkpoint
Submit in Brightspace:

1. a screenshot showing that you completed the MongoDB University lab
2. a short text response answering the questions below

## Short Response Questions
Answer in plain language:

1. What did Python need in order to connect to MongoDB Atlas?
2. What is one thing Atlas handles for you that you would otherwise need to manage yourself?
3. What is one thing you still need to be careful about even when using a managed cloud database?
4. How could this lab help with your final project if you choose MongoDB/Atlas?

## Success Standard
You are successful if you complete the MongoDB University lab and can explain, in your own words, how Python connects to a managed MongoDB Atlas database.
