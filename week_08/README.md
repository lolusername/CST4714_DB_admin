# Week 8 - Atlas, GitHub Student, JSON, and MongoDB Foundations

Week 7 now handles the short NoSQL bridge: history, why NoSQL re-emerged, and the major NoSQL families. Week 8 now has two connected parts:
- Part A: Atlas onboarding, GitHub Student, GitHub browser editing, and JSON foundations
- Part B: MongoDB document modeling foundations

This keeps the sequence cleaner:
1. students learn the platform and the data format first,
2. students practice representing CSV-style data as JSON,
3. students then move into MongoDB document thinking with better context.

## Materials
- `Week_08_JSON_Atlas_GitHub.pptx` - lecture deck on Atlas, GitHub Student, GitHub browser editing, and JSON history/syntax/flexibility.
- `atlas_github_student_checklist.md` - student-facing setup checklist for GitHub Student, Atlas, and browser editing.
- `github_student_application_guide.pdf` - PDF guide for applying to GitHub Student.
- `mongodb_student_certification_guide.pdf` - PDF guide for qualifying for MongoDB's student certification benefit.
- `json_quick_reference.md` - compact guide to JSON history, syntax, and multiple valid shapes.
- `in_class_assignment_json_from_csv.md` - in-class assignment using CSV "tables" and handwritten JSON examples only.
- `csv_case/` - the small CSV set used in the JSON assignment.
- `mongodb_nosql_intro.pptx` - lecture deck on MongoDB modeling, CRUD, aggregation, trade-offs, and DBA responsibilities.
- `mongodb_nosql_review_packet.md` - retrieval-practice handout spanning the Week 7 bridge and the MongoDB foundations content.

## Week Focus
- students get oriented to MongoDB Atlas and GitHub Student,
- students see how to use GitHub's browser editing workflow,
- students learn what JSON is, why it became popular, and what syntax rules matter,
- students practice converting CSV-style tables into more than one valid JSON structure,
- students connect JSON flexibility to later MongoDB document modeling.

## Recommended Flow
1. Start with `Week_08_JSON_Atlas_GitHub.pptx`.
2. Use `atlas_github_student_checklist.md` to keep onboarding lightweight and concrete.
3. Run `in_class_assignment_json_from_csv.md` with the files in `csv_case/`.
4. Use `json_quick_reference.md` as a syntax support handout during the assignment.
5. Transition into `mongodb_nosql_intro.pptx` once students have a stronger feel for JSON structure.
