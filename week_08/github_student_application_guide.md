# GitHub Student Application Guide

As of March 19, 2026, GitHub's official student application documentation says students can apply for GitHub Education if they are enrolled in a degree- or diploma-granting program, use a personal GitHub account, are at least 13 years old, and can verify student status with a school email or documents.

## Quick Version
1. Create or sign in to your personal GitHub account.
2. Verify your email address.
3. Go to the GitHub Student Developer Pack page.
4. Start the GitHub Education student application.
5. Submit your school email or proof of enrollment.
6. Wait for approval, then return to the GitHub Education portal to use your benefits.

## What To Have Ready
- your personal GitHub account,
- your school-issued email if you have one,
- or one document that proves current student status.

GitHub's docs say accepted proof may include:
- a school ID showing a current date,
- a class schedule,
- a transcript,
- or an enrollment verification letter.

## Step-By-Step
1. Open the GitHub Student Developer Pack page.
2. Sign in with your personal GitHub account.
3. Find the option to apply for GitHub Education as a student.
4. Enter the requested school information.
5. If asked, upload a clear image or file that proves current enrollment.
6. Submit the application.
7. After approval, return to the GitHub Education portal and activate the benefits you want to use.

## Common Delays
- Your GitHub email is not verified.
- You use a shared or school-managed account instead of your own personal account.
- The uploaded document does not clearly show that your enrollment is current.
- The name on your proof does not match the name on your GitHub account.
