# Atlas + GitHub Student Checklist

## Purpose
Use this checklist to get ready for later MongoDB work without running any queries yet.

This week is about:
- account setup,
- platform familiarity,
- browser-based editing,
- JSON practice.

---

## 1. GitHub Account
- confirm that you can sign in to your personal GitHub account,
- make sure you can create or access repositories,
- make sure your account email is verified.

Official reference:
- [GitHub repositories documentation](https://docs.github.com/en/repositories)

---

## 2. GitHub Student Developer Pack
- visit the GitHub Student Developer Pack page,
- review eligibility and application steps,
- apply if you have not already done so,
- keep a screenshot or note showing your application status.

Official references:
- [GitHub Student Developer Pack](https://education.github.com/pack)
- [GitHub Education](https://education.github.com/)

---

## 3. MongoDB Student Benefits
- review the MongoDB for Students page,
- note that MongoDB student benefits are tied to the GitHub Student Developer Pack,
- verify your status there if you are eligible.

Official reference:
- [MongoDB for Students](https://www.mongodb.com/students)

---

## 4. MongoDB Atlas Familiarity
- visit MongoDB's Get Started page,
- understand that Atlas is the cloud platform students will use later,
- make sure you know where sign-up, project creation, and cluster creation live in the UI.

You do not need to run any database commands for this week's assignment.

Official references:
- [MongoDB Get Started](https://www.mongodb.com/docs/get-started/)
- [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)

---

## 5. GitHub Browser Editing
Practice one of these browser-based editing paths:

### Option A - GitHub File Editor
- open a file in a repository,
- click the pencil/edit button,
- make a small text change,
- preview and commit.

### Option B - `github.dev`
- open a repository on GitHub,
- press `.` to open `github.dev`,
- create or edit a file in the browser,
- commit from the source control panel.

Official references:
- [Editing files on GitHub](https://docs.github.com/en/repositories/working-with-files/managing-files/editing-files)
- [The github.dev web-based editor](https://docs.github.com/en/codespaces/the-githubdev-web-based-editor)

---

## 6. Completion Check
By the end of this week, you should be able to say:
- I know what GitHub Student is and where to apply.
- I know what MongoDB Atlas is and why we will use it later.
- I can edit and commit a text file in the browser.
- I can write valid JSON in a text editor.
